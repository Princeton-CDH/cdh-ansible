# Architecture Decision Records

This directory captures long-lived architectural decisions using
[MADR](https://adr.github.io/madr/)-style records. Add a new ADR when a
decision affects the shape of future work (new conventions, tooling
choices, breaking layout changes); routine changes belong in commits and
pull requests, not here.

To start a new ADR, copy
[`template.md`](https://github.com/Princeton-CDH/cdh-ansible/blob/main/architecture-decisions/template.md),
give it the next sequential number, and follow the existing files as
examples.

```{toctree}
:maxdepth: 1
:glob:

0*
```
