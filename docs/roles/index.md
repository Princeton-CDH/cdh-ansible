# Roles

Reference documentation for local Ansible roles in the `roles/` directory.
Pages listed below are generated by
[antsibull-docs](https://ansible.readthedocs.io/projects/antsibull-docs/) from
each role's `meta/argument_specs.yml` file; the generator lives at
`docs/_ext/role_docs.py` and runs during every documentation build.

Only roles that opt in by providing an `argument_specs.yml` appear here.
